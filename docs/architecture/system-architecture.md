# 系统架构

## 组件

- uni-app / Vue 3：微信小程序与 H5 用户界面
- FastAPI：认证、空间、日记和媒体 REST API
- SQLAlchemy：数据访问层
- SQLite：本地开发；PostgreSQL：生产环境
- 本地上传目录：开发环境；腾讯云 COS：生产建议

## 数据流

前端通过 HTTPS 和 Bearer JWT 调用统一 API。服务端校验身份与空间成员关系后读写数据库。媒体先上传获得 ID，再随日记保存请求绑定。

## 安全边界

- 微信 AppSecret 和 JWT 密钥只存在服务端
- 服务端过滤私密日记，不能只依赖前端隐藏
- 用户只能修改或删除自己的日记
- 图片按空间隔离，并限制类型和体积
- 生产环境只允许明确配置的 CORS 来源

## 同步策略

MVP 采用请求式同步：保存立即写入服务端，列表通过进入页面或下拉刷新重新拉取。更新携带 `updated_at`，服务端发现版本不一致时返回 409。
