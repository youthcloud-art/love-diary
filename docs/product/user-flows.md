# 用户流程

## 首次使用

登录/注册 → 创建双人空间或输入邀请码 → 进入日记列表 → 写第一篇日记。

创建者获得短期邀请码；另一位用户使用邀请码加入后，两人共享同一空间。每个账号只能加入一个空间，每个空间最多两人。

## 写日记

进入“写下” → 选择日期和心情 → 输入内容 → 可选上传图片 → 选择共享或仅自己 → 保存并同步。

## 浏览与同步

进入“日记”查看倒序列表。下拉刷新后从服务器获取最新内容。共享内容双方可见，私密内容只出现在作者账号中。

## 异常流程

- 登录过期：返回登录页
- 邀请码失效：提示重新生成
- 空间已有两人：拒绝加入
- 内容被另一端更新：提示刷新后再编辑
- 图片不合规或超过 8 MB：阻止上传并说明原因
