# 产品需求文档（PRD）

## 产品定位

恋爱日记是一款仅服务两位用户的私密记录工具。两人可以从微信小程序或浏览器进入同一本日记，记录文字、心情与照片，并决定内容共享或仅自己可见。

## MVP 范围

1. 邮箱注册登录与微信小程序登录
2. 创建双人空间、邀请码加入、最多两名成员
3. 新增、查看、编辑和删除自己的日记
4. 日记日期、标题、正文、心情、照片和可见性
5. 共享内容双端同步；私密内容仅作者可见
6. 两端同时修改时提示冲突，避免静默覆盖

## 非目标

- 公开社交、关注、评论和陌生人匹配
- 多人群组日记
- MVP 阶段的实时协同编辑与端到端加密

## 核心验收指标

- 两位成员均能在 3 分钟内完成注册与绑定
- 保存成功后，另一端刷新即可看到共享日记
- 私密日记不会通过列表、详情或接口泄露给伴侣
- 图片上传失败、登录过期和编辑冲突均有明确提示
